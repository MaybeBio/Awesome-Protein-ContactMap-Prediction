RoseTTAFold2中的嵌入模块充当了原始输入数据与三轨架构之间的关键桥梁。这些模块将稀疏的生物信息——多序列比对（MSA）、模板结构和序列信息——转化为网络可以高效处理的密集、可学习的表示。理解这些嵌入对于掌握模型如何将进化和结构约束编码到其特征空间中至关重要。

## MSA嵌入架构

MSA嵌入模块（`MSA_emb`）负责协调将原始MSA特征转化为高维表示。该模块处理由`MSAFeaturize`选定的种子MSA（比对序列的子集），通过一个多阶段特征化流程，捕获进化信息、序列多样性和位置关系。

该模块接受维度为`d_init=48`的MSA特征，包括独热编码的氨基酸（22维）、聚类序列谱（22维）、插入统计（2维）和末端信息（2维）[network/featurizing.py#L33-L149]。转换首先通过一个线性投影，将这些稀疏特征映射到密集的`d_msa=256`维空间[network/Embeddings.py#L59]。

一个关键的架构洞察是双重嵌入策略：MSA接收一个线性变换（`self.emb`），而查询序列接收一个专门的嵌入（`self.emb_q`），该嵌入被加到所有MSA序列上[network/Embeddings.py#L92-L94]。这种设计确保了查询序列的特定特征被注入到整个MSA表示中，同时保留了同源序列的多样性。

<CgxTip>
将特定于查询的嵌入添加到所有MSA序列中，创建了一个通信通道，使网络能够区分目标序列及其同源物，这对于准确的结构预测至关重要。
</CgxTip>

## 成对表示生成

成对表示通过一种非对称构造产生，该构造通过序列内容和相对位置编码残基对残基的关系。该模块通过组合左右序列嵌入来生成这种表示，创建了一个外积结构，捕获行和列的残基信息[network/Embeddings.py#L97-L99]。

关键创新在于位置编码注入：`PositionalEncoding2D`将相对序列分离信息添加到成对特征中，编码序列空间中残基对之间的几何关系[network/Embeddings.py#L15-L52]。这种编码使用跨越-32到+32个位置的65个bin，允许网络学习序列空间中依赖于距离的模式。对于非共价复合物（nc_cycle=True），编码在链边界处环绕，使模型能够处理圆形或对称结构[network/Embeddings.py#L32-L33]。

最终的成对表示组合了这些组件：
```
pair[i,j] = emb_left(seq[i]) + emb_right(seq[j]) + positional_encoding(i-j)
```

这种加法结构保留了序列和位置信息的可分离性，同时使网络能够在后续处理中学习复杂的、非线性的交互。

## 状态表示

状态表示（`d_state=32`）提供了一个紧凑的每个残基的编码，作为2D成对特征和3D SE(3)-等变网络之间的主要接口[network/Embeddings.py#L63, #L103]。与捕获成对关系的成对表示不同，状态编码了将被转换为3D坐标的单个残基特征。

状态嵌入直接从查询序列通过学习的嵌入层初始化，使其成为三个核心表示中最具序列特异性的表示。在迭代优化循环中，状态从成对表示和3D坐标接收信息，创建一个反馈循环，使模型能够收敛到物理上现实的结构。

## 模板嵌入集成

模板结构通过`Templ_emb`模块提供显式的结构信息，该模块处理两个互补的信息流：2D成对特征和1D扭转角特征[network/Embeddings.py#L187-L336]。2D特征包括编码残基间距离的37个距离直方图bins、描述相对几何形状的6个方向参数以及一个掩码通道[network/Embeddings.py#L190-L192]。

模板嵌入流程遵循一个复杂的多阶段架构：

1. **特征融合**：该模块将2D模板特征（`t2d`）与来自行和列残基的平铺1D特征（`t1d`）连接起来，为每个残基对创建一个全面的88维表示[network/Embeddings.py#L233-L237]。

2. **结构偏向处理**：`TemplatePairStack`应用结构偏向的注意力机制，在通过从模板CA坐标计算的径向基函数（RBF）距离特征对查询结构进行条件处理的同时处理模板特征[network/Embeddings.py#L248-L270, #L297-L300]。

3. **基于注意力的信息传递**：该模块采用两种注意力机制——用于成对特征的`self.attn`和用于状态特征的`self.attn_tor`——将模板信息传递给查询表示[network/Embeddings.py#L206, #L210]。

注意力机制遵循交叉注意力模式，其中查询表示关注模板特征。对于成对特征，查询成对表示重塑为`(B*L*L, 1, d_pair)`并关注重塑为`(B*L*L, T, d_templ)`的模板特征，其中T是模板的数量[network/Embeddings.py#L321-L333]。这种设计使查询中的每个残基对能够从所有可用模板中提取相关信息，并通过学习的注意力分数进行加权。

<CgxTip>
模板嵌入中基于条带的计算在推理过程中通过分块处理特征矩阵来减少内存占用，从而能够在不超出GPU内存限制的情况下预测更大的蛋白质。
</cgt_tip>

## MSA特征化流程

在嵌入层接收MSA数据之前，`MSAFeaturize`函数执行关键预处理，将原始序列比对转化为结构化特征[network/featurizing.py#L33-L149]。该流程实现了几种复杂的数据增强策略：

1. **块删除**：随机删除连续块模拟了缺失序列区域的效果，提高了模型对不完整比对的鲁棒性。

2. **基于聚类的谱生成**：该算法根据汉明距离将额外的序列分配给聚类，然后计算加权的氨基酸频率，捕获进化保守模式[network/featurizing.py#L117-L132]。

3. **随机掩码策略**：遵循BERT范式，15%的位置经历随机替换：10%替换为均匀随机氨基酸，10%替换为MSA谱样本，80%替换为特殊的掩码令牌[network/featurizing.py#L74-L88]。

生成的种子MSA特征由四个部分组成：独热编码的氨基酸、聚类序列谱、插入统计和末端位置标志[network/featurizing.py#L143]。这种丰富的特征化使嵌入网络能够学习捕获进化约束和序列特定特征的复杂表示。

## 循环机制

循环机制通过将先前的预测反馈到嵌入网络中来实现迭代优化[network/Embeddings.py#L337-L412]。这个过程创建了一个自洽循环，模型通过多次迭代逐步改进其预测。

在循环期间，该模块使用层归一化对MSA和成对表示进行归一化，然后结合来自预测3D结构的几何信息[network/Embeddings.py#L366-L378]。关键创新在于使用几何关系从N、Cα和C原子重建Cβ坐标[network/Embeddings.py#L384-L385]，随后计算基于距离的RBF特征：

```python
dist_CB = rbf(torch.cdist(Cb, Cb))
```

这些距离特征与来自行和列视角（左右）的状态表示连接，然后通过学习的线性变换投影回成对表示空间[network/Embeddings.py#L401-L408]。这种设计允许模型基于物理上现实的3D约束优化成对关系，逐渐收敛到类似天然的结构。

## 与三轨架构的集成

嵌入模块通过`RoseTTAFoldModule.forward`方法与RoseTTAFold主模型直接接口，该方法协调三轨信息流[network/RoseTTAFoldModel.py#L52-L100]。模型为潜在MSA（`msa_latent`）和完整MSA（`msa_full`）维护单独的嵌入，其中潜在嵌入被循环，完整嵌入提供额外的序列上下文。

嵌入过程遵循以下顺序：

1. **初始嵌入**：`self.latent_emb`将种子MSA转化为潜在表示，而`self.full_emb`处理完整MSA[network/RoseTTAFoldModel.py#L71, #L76]。

2. **循环集成**：先前的迭代预测通过`self.recycle`被合并，向成对表示添加几何约束[network/RoseTTAFoldModel.py#L92-L98]。

3. **模板集成**：模板特征通过`self.templ_emb`集成，该模块更新成对和状态表示，并包含来自同源蛋白质的结构信息。

这种模块化设计使每种嵌入类型能够专门捕获蛋白质结构的不同方面：MSA嵌入捕获进化约束，成对表示编码几何关系，状态表示维持每个残基的特征，模板嵌入提供显式的结构先验。

## 特征维度和内存优化

嵌入模块实现了复杂的内存优化策略，以实现大型蛋白质的训练和推理：

- **基于条带的计算**：对于大序列，模块分块（条带）处理特征，而不是全矩阵，减少推理期间的峰值内存使用[network/Embeddings.py#L38-L48, #L228-L244]。

- **梯度检查点**：可选的激活重新计算以额外计算为代价减少训练期间的内存[network/Embeddings.py#L309-L310, #L323-L324]。

- **精度处理**：模块维护谨慎的数据类型管理，在计算和全精度之间转换半精度（bfloat16/float16），并在需要时保持稳定性[network/Embeddings.py#L96-L98, #L377-L378]。

这些优化对于模板嵌入尤为重要，后者处理多个模板，每个模板都需要完整的（L×L）成对特征矩阵。基于条带的方法能够在单GPU系统上预测长达数百个残基的蛋白质。
