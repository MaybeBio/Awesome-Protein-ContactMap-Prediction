手性处理对于准确的蛋白质结构预测至关重要，因为立体化学的正确性直接影响生成模型的物理真实性和功能可行性。RoseTTAFold-All-Atom 实现了一个全面的手性管理系统，确保预测的结构在蛋白质残基和小分子配体中都能保持正确的立体化学。

## 手性检测与枚举

系统根据结构是蛋白质残基还是小分子配体，采用不同的策略来检测手性。这种双路径方法结合了硬编码的生物化学知识和自动化的立体化学分析。

### 蛋白质残基手性

蛋白质手性检测基于残基的原子化表示进行，利用了标准氨基酸中手性中心的预编码知识。`kinematics.py` 中的 `get_atomize_protein_chirals()` 函数通过以下方式系统地枚举手性中心：

1. 从化学数据库中识别手性原子（`ChemData().aachirals`）
2. 定位每个手性原子的键合邻居（通常是三个重原子）
3. 构成定义手性四面体的原子四元组
4. 计算伪二面角以确定立体化学

核心实现认识到所有蛋白质手性中心都具有三个重原子邻居的四面体几何形状，从而允许高效的张量操作：

```python
chiral_bonds_idx = chiral_bonds_idx.reshape(num_chiral_centers, 3, 2)
chirals[:,0] = chiral_atoms.long()
chirals[:, 1:-1] = chiral_bonds_idx[...,-1].long()
chirals[:, -1] = angle  # arcsin(1/√3) 用于完美的四面体几何结构
```

来源：[kinematics.py](rf2aa/kinematics.py#L282-L312)

### 小分子手性

对于小分子和配体，系统通过 `kinematics.py` 中的 `get_chirals()` 函数集成了 OpenBabel 的立体化学分析能力。这种方法提供了：

- 使用 `OBStereoFacade` 进行自动四面体立体化学检测
- 提取立体中心构型（R/S 指定）
- 为每个手性中心生成原子四元组
- 根据原子坐标计算观测到的伪二面角

该函数遍历分子中的所有原子，识别具有四面体立体化学的原子，并提取定义手性中心的中心原子和三个参考原子。重要的是，它生成原子排序的多种排列组合以处理立体化学对称性：

```python
for a, b, c in permutations((c,i,j,k), 3):
    chiral_idx_set.add(standardize_dihedral_retain_first(o,a,b,c))
```

来源：[kinematics.py](rf2aa/kinematics.py#L250-L280), [kinematics.py](rf2aa/kinematics.py#L246-L248)

## 手性损失计算

在模型训练期间确保正确的立体化学是通过专门的损失函数实现的，该函数会对偏离理想手性角的情况进行惩罚。`loss/loss.py` 中的 `calc_chiral_loss()` 函数计算所有手性中心的预测伪二面角与理想伪二面角之间的均方误差。

### 数学基础

理想四面体角计算为 θ = arcsin(1/√3) ≈ 35.26°，代表由中心原子和两对相邻原子形成的平面之间的伪二面角。对于由原子 (A, B, C, D) 定义的每个手性中心，其中 A 是中心原子：

- 正伪二面角：(B, C, D) 呈右手螺旋排列（R-立体化学）
- 负伪二面角：(B, C, D) 呈左手螺旋排列（S-立体化学）

损失计算提取每个原子四元组的预测坐标，计算实际伪二面角，并将其与目标进行比较：

```python
pred_dih = get_dih(chiral_dih[...,0, :], chiral_dih[...,1, :], 
                   chiral_dih[...,2, :], chiral_dih[...,3, :])
l = torch.square(pred_dih - chirals[...,-1]).mean()
```

来源：[loss/loss.py](rf2aa/loss/loss.py#L190-L204), [kinematics.py](rf2aa/kinematics.py#L286-L287)

### 梯度计算

为了在训练期间实现端到端的可微分性，`loss/loss.py` 中的 `calc_chiral_grads()` 计算手性损失相对于原子坐标的梯度。这使得立体化学约束能够在整个网络架构中进行反向传播。

<CgxTip>在训练早期，手性损失通常使用的权重低于空间位阻损失，然后逐渐增加，以确保在达到大致的折叠准确性后保证立体化学的正确性。</CgxTip>

来源：[loss/loss.py](rf2aa/loss/loss.py#L234-L241)

## 生物分子系统中的手性类型

### 蛋白质手性中心

蛋白质残基包含几个规范的手性中心，最显著的是所有 L-氨基酸中的 Cα 原子。`chemical.py` 中的化学数据库编码了理想坐标和原子连通性，为所有 20 种标准氨基酸隐式定义了手性。

| 残基类型 | 主要手性中心 | 附加手性中心 |
|--------------|----------------------|---------------------------|
| 所有 L-氨基酸 | Cα (N, H, C, CB) | 侧链原子 |
| 丙氨酸 | Cα | 无 |
| 苏氨酸 | Cα, Cβ | - |
| 异亮氨酸 | Cα, Cβ | - |

原子化表示允许灵活处理标准和非标准残基，手性检测根据原子连通性自动适应。

来源：[chemical.py](rf2aa/chemical.py#L400-L700)

### 小分子手性

小分子配体呈现出多样的立体化学构型，包括：

- **四面体中心**：sp³ 杂化碳原子上的 R/S 立体化学
- **轴向手性**：具有受限旋转的阻旋异构键
- **平面手性**：大环化合物和金属茂中的特殊情况

OpenBabel 的立体化学检测能够透明地处理这些情况，无论具体的立体化学分类如何，手性枚举过程都会生成适当的原子四元组。

## 手性检测工作流

```mermaid
flowchart TD
    A[输入结构] --> B{结构类型}
    B -->|蛋白质| C[加载化学数据]
    B -->|小分子| D[初始化 OpenBabel 分子]
    
    C --> E[访问 aachirals 数据库]
    E --> F[识别手性原子索引]
    F --> G[提取键合邻居]
    G --> H[形成原子四元组]
    
    D --> I[创建 OBStereoFacade]
    I --> J[检测四面体中心]
    J --> K[提取立体化学构型]
    K --> L[生成排列组合]
    L --> M[标准化原子排序]
    
    H --> N[计算伪二面角]
    M --> N
    N --> O[确定符号 +/-]
    O --> P[创建 Chirals 张量<br/>(n_chiral, 5)]

    Q --> R[梯度反向传播]
```

该工作流展示了蛋白质和小分子手性检测如何收敛于通用的表示格式（带有目标角度的原子四元组），同时使用适合每种分子类型的专门检测机制。

## 实现注意事项

### 坐标系标准化

`kinematics.py` 中的 `standardize_dihedral_retain_first()` 函数通过应用规范排列规则，确保手性四元组中的原子排序一致。这种标准化对于以下方面至关重要：

- 跨不同批次顺序的一致损失计算
- 无论输入文件格式如何，都能可重现地检测手性
- 结构生成期间正确的立体化学分配

### 张量操作与效率

蛋白质手性检测利用 PyTorch 的张量操作来提高效率：

```python
chirals = chirals.repeat(3,1).float()
chirals[n:2*n,1:-1] = torch.roll(chirals[n:2*n,1:-1],1,1)
chirals[2*n: ,1:-1] = torch.roll(chirals[2*n: ,1:-1],2,1)
```

这将创建手性四面体配体的所有三个有效排列，计算每个排列的伪二面角，并根据实际立体化学选择适当的符号。

来源：[kinematics.py](rf2aa/kinematics.py#L290-L297)

### 边缘情况与验证

手性处理系统包含对边缘情况的稳健处理：

- **甘氨酸**：Cα 处无手性（两个 H 原子）
- **无序原子**：通过 `residue_atomize_mask` 自动掩蔽
- **多个手性中心**：每个中心独立处理
- **脯氨酸**：环闭合中 N-Cδ 键的特殊处理

<CgxTip>当处理具有模糊立体化学的结构（例如，外消旋混合物或分辨率较差的密度）时，系统默认为训练数据中发现的最常见的立体化学构型。</CgxTip>

## 与模型架构的集成

手性约束集成在 RoseTTAFold-All-Atom 架构的多个点：

1. **数据加载**：Chirals 张量在预处理期间计算
2. **前向传播**：在遵守手性约束的同时细化坐标
3. **损失计算**：手性损失添加到总损失函数中
4. **结构输出**：验证最终坐标的立体化学正确性

这种多层方法确保立体化学约束在整个推理流程中指导结构预测，从初始坐标生成到最终细化。
