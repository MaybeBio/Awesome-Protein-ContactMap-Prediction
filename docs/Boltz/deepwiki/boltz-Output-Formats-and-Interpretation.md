 This page documents the output files generated by Boltz predictions, their formats, and how to interpret the various confidence and affinity metrics\. This covers the final stage of the prediction pipeline where model outputs are written to disk and structured for downstream use\.

 For information about running predictions and configuring output options, see [Command\-Line Interface](https://deepwiki.com/jwohlwend/boltz/2.1-command-line-interface)\. For details about the model architectures that generate these predictions, see [Model Architecture](https://deepwiki.com/jwohlwend/boltz/3-model-architecture)\.

## Overview

 After running `boltz predict`, the system generates a structured output directory containing:

 1. **Structure files** \- Predicted 3D coordinates in mmCIF or PDB format
2. **Confidence metrics** \- Per\-residue and global quality scores in JSON and NPZ formats
3. **Affinity predictions** \- Binding strength predictions for protein\-ligand complexes \(Boltz\-2 only\)

 Multiple samples are generated per prediction \(default: 5 for affinity, 1 otherwise\) and ranked by confidence score\. All outputs are organized into subdirectories by input file name\.

 **Sources:** [prediction\.md?plain=1 L174-L196](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L174-L196)

## Output Directory Structure

 The prediction outputs follow a hierarchical organization:

| Directory | Purpose |
| --- | --- |
| predictions/ | Contains subdirectories for each input file with structure and metric files |
| predictions/\[input\]/ | Individual prediction results, with multiple samples ranked by confidence |
| processed/ | Cached preprocessed data used during inference |
| lightning\_logs/ | Training/evaluation logs \(if applicable\) |

 The number of structure files \(`_model_0.cif`, `_model_1.cif`, etc\.\) is controlled by the `--diffusion_samples` flag \(default: 1 for structure\-only, 5 for affinity predictions\)\.

 **Sources:** [prediction\.md?plain=1 L174-L196](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L174-L196)

## Structure File Formats

### mmCIF Format

 The default output format is mmCIF \(Macromolecular Crystallographic Information File\), generated by the `to_mmcif()` function\. This format provides rich metadata and is preferred for modern structural bioinformatics\.

  Key features of the mmCIF output:

 - **Entity definitions** \- Unique molecular entities with sequence information
- **Asymmetric units** \- Chain instances mapped to entities
- **Atomic coordinates** \- Full 3D coordinates with 5 decimal precision
- **pLDDT scores** \- Embedded in B\-factor \(temperature factor\) field, scaled 0\-100
- **Chemical component** \- Residue types from standard dictionaries \(PDB CCD\)
- **Quality metrics** \- `_LocalPLDDT` records for per\-residue confidence

 The writer handles different molecule types appropriately:

 - Proteins: `ihm.LPeptideAlphabet`
- DNA: `ihm.DNAAlphabet`
- RNA: `ihm.RNAAlphabet`
- Ligands: `ihm.NonPolymerChemComp` or `ihm.SaccharideChemComp`

 **Sources:** [mmcif\.py L17-L306](https://github.com/jwohlwend/boltz/blob/cb04aecc/src/boltz/data/write/mmcif.py#L17-L306)

### PDB Format

 PDB format can be selected with `--output_format pdb`\. While more widely supported by legacy tools, it lacks some metadata present in mmCIF\.

  Key characteristics:

 - **Fixed\-width columnar format** \- 80 characters per line
- **pLDDT in B\-factor** \- Same as mmCIF, confidence scores scaled to 0\-100
- **CONECT records** \- Bond connectivity for ligands and inter\-residue bonds
- **TER records** \- Mark chain boundaries \(omitted for last chain\)
- **Element symbols** \- Derived from atom names or periodic table

 The `to_pdb()` function handles both Boltz\-1 and Boltz\-2 atom naming conventions through the `boltz2` flag, which affects element symbol determination\.

 **Sources:** [pdb\.py L11-L173](https://github.com/jwohlwend/boltz/blob/cb04aecc/src/boltz/data/write/pdb.py#L11-L173)

## Confidence Metrics

### JSON Confidence File

 Each sample includes a `confidence_[input]_model_N.json` file with aggregated quality metrics:

  **Sources:** [prediction\.md?plain=1 L198-L225](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L198-L225)

### Confidence Score Types

| Metric | Range | Interpretation | Use Case |
| --- | --- | --- | --- |
| confidence\_score | \[0, 1\] | Higher = better overall quality | Ranking samples |
| plddt | \[0, 1\] | Higher = more accurate local structure | Identifying well\-predicted regions |
| ptm | \[0, 1\] | Higher = better global fold | Single\-chain quality assessment |
| iptm | \[0, 1\] | Higher = better interface prediction | Multi\-chain complex quality |
| pde | Angstroms | Lower = more confident distances | Distance uncertainty estimation |
| ligand\_iptm | \[0, 1\] | Protein\-ligand interface quality | Binding pose confidence |
| protein\_iptm | \[0, 1\] | Protein\-protein interface quality | Oligomer assembly confidence |

 **Score Interpretation Guidelines:**

 - **pLDDT \> 90**: Very high confidence, typically near\-experimental accuracy
- **pLDDT 70\-90**: High confidence, good model quality
- **pLDDT 50\-70**: Low confidence, uncertain structure
- **pLDDT < 50**: Very low confidence, likely disordered or incorrect
- **PTM/iPTM \> 0\.8**: High confidence prediction
- **PTM/iPTM 0\.5\-0\.8**: Moderate confidence
- **PTM/iPTM < 0\.5**: Low confidence

 **Sources:** [prediction\.md?plain=1 L198-L227](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L198-L227)

### NPZ Metric Files

 For detailed analysis, per\-token metrics are saved as NumPy arrays:

| File | Content | Shape | Units |
| --- | --- | --- | --- |
| plddt\_\[input\]\_model\_N\.npz | Per\-token pLDDT scores | \(num\_tokens,\) | \[0, 1\] |
| pae\_\[input\]\_model\_N\.npz | Predicted Aligned Error matrix | \(num\_tokens, num\_tokens\) | Angstroms |
| pde\_\[input\]\_model\_N\.npz | Predicted Distance Error matrix | \(num\_tokens, num\_tokens\) | Angstroms |

 These files are generated by default\. To enable full PAE/PDE matrix output, use:

 - `--write_full_pae` for complete PAE matrix
- `--write_full_pde` for complete PDE matrix

 **Sources:** [prediction\.md?plain=1 L186-L189](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L186-L189) [prediction\.md?plain=1 L171-L172](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L171-L172)

## Affinity Predictions \(Boltz\-2\)

 When the `properties` field in the input YAML includes `affinity`, Boltz\-2 generates an `affinity_[input].json` file with binding strength predictions\.

### Affinity JSON Structure

| Field | Description | Range/Units |
| --- | --- | --- |
| affinity\_pred\_value | Ensemble prediction of binding affinity | log₁₀\(IC50\) in μM |
| affinity\_probability\_binary | Ensemble prediction of binding probability | \[0, 1\] |
| affinity\_pred\_value1 | Affinity from first model in ensemble | log₁₀\(IC50\) in μM |
| affinity\_probability\_binary1 | Binary probability from first model | \[0, 1\] |
| affinity\_pred\_value2 | Affinity from second model in ensemble | log₁₀\(IC50\) in μM |
| affinity\_probability\_binary2 | Binary probability from second model | \[0, 1\] |

 **Sources:** [prediction\.md?plain=1 L228-L238](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L228-L238)

### Interpreting Affinity Values

#### affinity\_pred\_value \(Regression\)

 This metric reports binding affinity as **log₁₀\(IC50\)** where IC50 is measured in **micromolar \(μM\)**:

| log₁₀\(IC50\) | IC50 | Binding Strength | Example |
| --- | --- | --- | --- |
| \-3 | 10⁻⁹ M \(1 nM\) | Strong binder | High\-affinity drug |
| \-1 | 10⁻⁷ M \(100 nM\) | Moderate binder | Lead compound |
| 0 | 10⁻⁶ M \(1 μM\) | Moderate binder | Early hit |
| 1 | 10⁻⁵ M \(10 μM\) | Weak binder | Screening hit |
| 2 | 10⁻⁴ M \(100 μM\) | Weak binder / Decoy | Likely inactive |

 **Important:** This head should only be used when comparing different **active molecules**\. It is not suitable for distinguishing binders from non\-binders, as it was trained only on active compounds\.

 **Conversion to pIC50 \(kcal/mol\):**

```
pIC50 = (6 - y) × 1.364
```

 where `y` is the model's prediction\.

 **Sources:** [prediction\.md?plain=1 L244-L249](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L244-L249)

#### affinity\_probability\_binary \(Classification\)

 This metric predicts the **probability that a ligand is a binder** \(vs\. a decoy\), ranging from 0 to 1:

| Probability | Interpretation | Use Case |
| --- | --- | --- |
| \> 0\.8 | High confidence binder | Prioritize for experimental validation |
| 0\.5 \- 0\.8 | Moderate confidence | Secondary screening candidates |
| < 0\.5 | Likely decoy/non\-binder | Deprioritize |

 This head should be used for:

 - **Virtual screening** \- Filtering large compound libraries
- **Hit discovery** \- Distinguishing potential binders from decoys
- **Docking validation** \- Assessing whether predicted binding modes are plausible

 **Sources:** [prediction\.md?plain=1 L240-L243](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L240-L243) [README\.md?plain=1 L52-L53](https://github.com/jwohlwend/boltz/blob/cb04aecc/README.md?plain=1#L52-L53)

### Affinity Prediction Requirements

 Affinity predictions have specific constraints:

 - **Target:** Must be a **protein** \(RNA/DNA/cofactor targets will produce unreliable outputs\)
- **Ligand:** Must be a single **ligand chain** \(not protein/DNA/RNA\)
- **Size limit:** ≤ 128 atoms \(heavy atoms \+ hydrogens kept by RDKit `RemoveHs`\)
- **Recommended limit:** ≤ 56 atoms \(training data limit for optimal performance\)

 **Sources:** [prediction\.md?plain=1 L104](https://github.com/jwohlwend/boltz/blob/cb04aecc/docs/prediction.md?plain=1#L104-L104)

## Sample Ranking

 Multiple samples are generated per prediction and ranked by `confidence_score`:

 1. **Generate samples** \- Number controlled by `--diffusion_samples` \(default: 1 for structure, 5 for affinity\)
2. **Compute confidence** \- Calculate `0.8 * complex_plddt + 0.2 * iptm` \(or `ptm` for single chains\)
3. **Sort by confidence** \- Rank samples from highest to lowest confidence
4. **Write outputs** \- Name files `_model_0` \(best\), `_model_1`, \.\.\., `_model_N-1` \(worst\)

 The best sample \(`_model_0`\) typically represents the most reliable prediction, though examining multiple samples can reveal alternative conformations or binding modes\.

 For affinity predictions, separate ensemble models can be used:

 - `--sampling_steps_affinity` \- Sampling steps for affinity \(default: 200\)
- `--diffusion_samples_affinity` \- Number of samples for affinity \(default: 5\)
- `--affinity_checkpoint` \- Optional separate checkpoint for affinity predictions
