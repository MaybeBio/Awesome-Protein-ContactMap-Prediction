The `scripts/` directory contains the production-ready Python and Bash scripts that orchestrate the bAIes-IDP workflow. These scripts are designed for robust execution and provide command-line interfaces for various stages of the pipeline, serving as the backbone for both the tutorials and benchmark simulations. While the `tutorial/` directory demonstrates the workflow with specific examples, the scripts in `scripts/` are generalized and parameterized for broader application.

This parent page provides a high-level overview of each script and its role in the overall bAIes-IDP pipeline. For detailed information on arguments, usage, and specific functionalities, please refer to the dedicated child pages linked below.

## 6.1. preprocess_bAIes.py – CLI Reference

The `preprocess_bAIes.py` script is a crucial component for preparing AlphaFold2 (AF2) or ColabFold distogram predictions for use with the BAIES PLUMED module. It takes raw distogram data, fits statistical models (Gaussian or lognormal) to the distance distributions, and applies residue-pair specific cutoffs to generate the `baies_params.dat` file and an atom index file (`atom_list.ndx`). These output files are essential inputs for the BAIES PLUMED action, which biases the molecular dynamics simulation.

For a comprehensive list of command-line arguments, details on the Baker-lab residue-pair cutoff matrix, and an explanation of the Gaussian/lognormal fitting procedure, see [preprocess_bAIes.py – CLI Reference](/COSBlab/bAIes-IDP/6.1-preprocess_baies.py-cli-reference).

## 6.2. make_ff.py – CLI Reference

The `make_ff.py` script (originally named `remove_nonbonded_cmap_plumed.py` in the `step3-conversion.bash` script) is responsible for modifying the force field parameters generated by `intermol` and integrating CMAP corrections. It reads the LAMMPS input and topology files produced by `intermol`, injects CMAP crossterms, rewrites pair coefficients to implement the Random Coil model, and sets up the simulation box. This script is a critical step in transitioning from a GROMACS-compatible topology to a LAMMPS-ready simulation setup with the bAIes-IDP specific force field modifications.

For a full reference of its command-line arguments, and an explanation of how it processes `intermol` output, injects CMAP crossterms, and modifies pair coefficients for the Random Coil model, see [make_ff.py – CLI Reference](/COSBlab/bAIes-IDP/6.2-make_ff.py-cli-reference).

## 6.3. Shell Scripts (step1, step2, step3)

The `scripts/` directory also contains three Bash shell scripts that orchestrate the main stages of the bAIes-IDP pipeline:

* `step1-prepare_gmx.bash`: Prepares GROMACS topology files from an input PDB.
* `step2-preprocess.bash`: Executes `preprocess_bAIes.py` to generate distogram preprocessing files.
* `step3-conversion.bash`: Manages the `intermol` conversion from GROMACS to LAMMPS and then calls `make_ff.py` for force field modifications.

These scripts streamline the workflow by chaining together the Python utilities and external tools like GROMACS and `intermol`. They are designed to be executed sequentially, guiding the user through the necessary steps to prepare a protein for bAIes-IDP simulation.

For detailed information on the arguments, environment requirements, and expected outputs of each of these orchestration scripts, see [Shell Scripts (step1, step2, step3)](/COSBlab/bAIes-IDP/6.3-shell-scripts-(step1-step2-step3)).
