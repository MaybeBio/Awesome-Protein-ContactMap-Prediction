This page provides a detailed reference for the `baies_params.dat` and `baies_gauss_matrix.dat` files, which are crucial for configuring the BAIES Bayesian bias module in PLUMED. These files define the specific distance restraints and their associated Gaussian parameters used to guide the molecular dynamics (MD) simulation towards AlphaFold-predicted conformations. We will cover the file format, how atom indices are mapped, and the distinction between the `JEFFREYS` and `NONE` priors.

## baies_params.dat / baies_gauss_matrix.dat Format

Both `baies_params.dat` (used in tutorials) and `baies_gauss_matrix.dat` (used in benchmarks) share the same fundamental structure. These files are generated by the `preprocess_bAIes.py` script [scripts/preprocess_bAIes.py](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/scripts/preprocess_bAIes.py)

### FIELDS Format

The first two lines of these files are header comments specifying the data fields and the model type:

```
#! FIELDS Id atom_i atom_j mu sigma
#! SET model gaussian
```

[tutorial/bAIes/4-simulation/baies_params.dat L1-L2](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/baies_params.dat#L1-L2)

* `Id`: A unique identifier for each distance restraint.
* `atom_i`: The 1-based index of the first atom involved in the distance restraint.
* `atom_j`: The 1-based index of the second atom involved in the distance restraint.
* `mu`: The mean (expected value) of the Gaussian distribution for the distance between `atom_i` and `atom_j`. This value is derived from the AlphaFold distogram.
* `sigma`: The standard deviation of the Gaussian distribution for the distance between `atom_i` and `atom_j`. This value reflects the uncertainty or spread around the mean distance, also derived from the AlphaFold distogram.

Subsequent lines in the file contain the actual data, with each line representing a single distance restraint. For example:

```
1 57 127 1.056467 0.266714
2 79 127 0.851589 0.199167
...
```

[tutorial/bAIes/4-simulation/baies_params.dat L3-L4](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/baies_params.dat#L3-L4)

This indicates that for restraint `1`, the distance between atom `57` and atom `127` is expected to be `1.056467` (in nanometers, as `units real` is used in LAMMPS [tutorial/bAIes/4-simulation/idp_nvt.in L1](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/idp_nvt.in#L1-L1)

), with a standard deviation of `0.266714`.

### SET Model Gaussian

The line `#! SET model gaussian` [tutorial/bAIes/4-simulation/baies_params.dat L2](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/baies_params.dat#L2-L2)

 explicitly tells the PLUMED BAIES module that the statistical model used for these restraints is a Gaussian distribution. The `preprocess_bAIes.py` script can also fit lognormal distributions, but the current implementation of the BAIES PLUMED action expects Gaussian parameters.

## Atom Index Mapping and atom_list.ndx

The `atom_i` and `atom_j` indices in `baies_params.dat` (or `baies_gauss_matrix.dat`) refer to the 1-based atom indices within the simulation system. These indices correspond to the atom numbering in the LAMMPS data file (e.g., `idp_nvt.data` [tutorial/bAIes/4-simulation/idp_nvt.data](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/idp_nvt.data)

) and the PDB file (e.g., `idp.pdb` [tutorial/bAIes/4-simulation/idp.pdb](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/idp.pdb)

).

The `atom_list.ndx` file [tutorial/bAIes/4-simulation/atom_list.ndx](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/atom_list.ndx)

 plays a crucial role in defining the `batoms` group for the PLUMED `BAIES` action. This file lists all atoms that are part of *any* distance restraint defined in `baies_params.dat`.

```
[ batoms ]
57 79 91 103 115 127 149 163 187 197 230 258 274 285 300 
320 335 349 368 383 400 415 429 440 461 475 490 514 533 557 
567 589 605 615 629 640 669 743 765 776 793 805 820 836 851 
875 899 916 926 941 965 985 995 1017 1034 1058 1080 1095 1119 1130 
1152
```

[tutorial/bAIes/4-simulation/atom_list.ndx L1-L6](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/atom_list.ndx#L1-L6)

The `plumed.dat` file then uses this index file to define the `batoms` group:

```yaml
batoms: GROUP NDX_FILE=atom_list.ndx NDX_GROUP=batoms
```

[tutorial/bAIes/4-simulation/plumed.dat L2](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/plumed.dat#L2-L2)

This ensures that PLUMED correctly identifies the atoms whose distances are to be biased according to the `baies_params.dat` file.

## bAIes (JEFFREYS prior) vs. bAIes-N (NONE prior)

The `BAIES` PLUMED action [tutorial/bAIes/4-simulation/plumed.dat L3](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/plumed.dat#L3-L3)

 supports different prior distributions for the Bayesian inference. This choice significantly impacts how the bias potential is calculated and applied during the MD simulation.

### bAIes (JEFFREYS prior)

In the standard `bAIes` simulations, the `PRIOR=JEFFREYS` option is used in the `plumed.dat` file:

```yaml
baies: BAIES ATOMS=batoms DATA_FILE=baies_params.dat PRIOR=JEFFREYS TEMP=2.478541306
```

[tutorial/bAIes/4-simulation/plumed.dat L3](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/plumed.dat#L3-L3)

The Jeffreys prior is a non-informative prior distribution often used in Bayesian statistics. When applied to the `BAIES` action, it means that the bias potential is derived assuming no prior knowledge about the distribution of distances, other than what is provided by the AlphaFold distogram. This approach aims to maximize the information gained from the AlphaFold data while minimizing the influence of arbitrary assumptions. The `TEMP` parameter [tutorial/bAIes/4-simulation/plumed.dat L3](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/plumed.dat#L3-L3)

 is the simulation temperature in energy units (e.g., kJ/mol or kcal/mol, depending on the `units` setting in LAMMPS [tutorial/bAIes/4-simulation/idp_nvt.in L1](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/tutorial/bAIes/4-simulation/idp_nvt.in#L1-L1)

), which scales the bias.

### bAIes-N (NONE prior)

The `bAIes-N` simulations, as seen in the benchmark directory [benchmark/bAIes-N/Ab40/plumed_Ab40.dat](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/benchmark/bAIes-N/Ab40/plumed_Ab40.dat)

 use `PRIOR=NONE`:

```yaml
baies: BAIES ATOMS=batoms DATA_FILE=baies_gauss_matrix.dat PRIOR=NONE TEMP=2.478541306
```

[benchmark/bAIes-N/Ab40/plumed_Ab40.dat L3](https://github.com/COSBlab/bAIes-IDP/blob/16faa7f7/benchmark/bAIes-N/Ab40/plumed_Ab40.dat#L3-L3)

When `PRIOR=NONE` is specified, the Bayesian inference framework is effectively simplified. Instead of incorporating a Jeffreys prior, the bias potential is directly proportional to the negative logarithm of the product of the Gaussian probabilities for each distance restraint. This can be thought of as a "maximum likelihood" approach where the system is directly driven towards the mean distances specified in `baies_gauss_matrix.dat` without the additional entropic contribution from the Jeffreys prior.

The scientific rationale for `bAIes-N` is to investigate the impact of the Jeffreys prior on the resulting conformational ensemble. By comparing `bAIes` and `bAIes-N` simulations, researchers can assess how the choice of prior influences the sampling of IDP conformations and the agreement with experimental data.
