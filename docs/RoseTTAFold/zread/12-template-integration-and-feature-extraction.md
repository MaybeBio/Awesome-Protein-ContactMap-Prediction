模板集成和特征提取是 RoseTTAFold 三轨道神经网络架构的关键组成部分，使模型能够利用同源蛋白质的结构信息来提高预测准确性。此过程将原始模板数据转换为丰富的特征表示，指导蛋白质结构预测流程。

## 模板处理流程

模板集成始于解析 HHsearch 结果并从识别的模板中提取结构信息。[`network/parsers.py`](network/parsers.py#L174-L239) 中的 `parse_templates` 函数通过将 `.atab` 文件中的比对信息与 `.hhr` 文件中的统计数据相结合来处理模板命中，然后从存储在 FFDB 数据库中的 PDB 结构中提取 3D 坐标。

模板处理工作流程遵循以下关键步骤：

1. **比对处理**：从表格化的 HHsearch 输出中提取匹配位置和位置得分
2. **统计集成**：整合包括概率、E 值和比对得分在内的每次命中统计数据
3. **结构提取**：从模板结构中解析 PDB 坐标和残基级特征
4. **特征映射**：将模板位置映射到查询序列位置以实现特征对齐

生成的模板数据包括：
- **3D 坐标** (`xyz_t`)：来自模板结构的 N、Cα、C 原子位置
- **位置映射** (`qmap`)：模板与查询序列位置之间的映射关系
- **1D 特征** (`t0d`)：模板级统计数据（概率、E 值、相似性得分）
- **2D 特征** (`t1d`)：位置特异性得分和比对质量

## 模板特征编码

提取的模板特征通过 [`network/Embeddings.py`](network/Embeddings.py#L82-L122) 中的 `Templ_emb` 类进行复杂编码。该模块实现了受 trRosetta-tbm 启发的逐像素注意力机制，将原始模板数据转换为有意义的嵌入。

模板编码架构结合了多个信息源：

### 特征组成
编码过程连接四个关键特征组件：
- **2D 模板信息** (`t2d`)：10 维成对特征，表示残基间关系
- **1D 模板特征** (`t1d`)：通过广播扩展为成对表示
- **序列间距**：对数转换的序列距离，提供位置上下文
- **结构上下文**：模板衍生的几何和进化信息

### 基于注意力的处理
编码特征通过序列维度（L 轴）的轴向注意力机制，使模型能够捕获长程依赖关系并为每个残基对识别最相关的模板信息。注意力权重通过学习投影计算，并使用 softmax 归一化以创建模板特征的加权组合。

<CgxTip>
模板嵌入使用复杂的注意力机制，根据序列间距和结构兼容性动态加权模板信息，使模型能够专注于目标蛋白质不同部分的最相关模板区域。
</CgxTip>

## 与三轨道架构的集成

模板特征通过主模型模块无缝集成到 RoseTTAFold 的三轨道架构中。在 [`network/RoseTTAFoldModel.py`](network/RoseTTAFoldModel.py#L41-L60) 中，模板嵌入在 `pair_emb` 模块中与序列和 MSA 特征结合：

```python
if self.use_templ:
    tmpl = self.templ_emb(t1d, t2d, idx)
    pair = self.pair_emb(seq, idx, tmpl)
else:
    pair = self.pair_emb(seq, idx)
```

`Pair_emb_w_templ` 类处理模板信息与成对序列特征的集成，创建包含以下内容的统一表示：
- **序列嵌入**：独热编码的氨基酸表示
- **模板嵌入**：来自同源蛋白质的处理结构信息
- **位置编码**：序列位置上下文

此集成表示作为特征提取流程的输入，影响 6D 坐标预测和迭代结构优化过程。

## 模板选择与质量控制

[`network/parsers.py`](network/parsers.py#L240-L256) 中的 `read_templates` 函数实现了智能模板选择和质量控制：

1. **模板排序**：根据 HHsearch 得分和比对质量选择模板
2. **位置映射**：使用比对信息将模板坐标映射到查询序列位置
3. **质量过滤**：自动过滤比对覆盖不足（< 10 个残基）的模板
4. **特征归一化**：模板得分归一化（除以 100.0）以确保稳定训练

系统通过 `n_templ` 参数支持可配置的模板数量，允许用户通过为其特定用例选择最佳模板数量来平衡计算效率和预测准确性。

## 对结构预测的影响

模板集成通过提供以下内容显著增强 RoseTTAFold 的预测能力：

- **结构先验**：模板提供指导折叠过程的 3D 结构约束
- **进化信息**：模板统计数据包含进化关系和结构保守性
- **长程接触**：模板衍生的距离约束改善蛋白质拓扑预测
- **域架构**：模板帮助识别域边界和域间关系

模板特征流经整个预测流程，通过 [`network/DistancePredictor.py`](network/DistancePredictor.py#L9-L37) 中的 `DistanceNetwork` 影响 6D 坐标预测，最终贡献于更准确的蛋白质结构模型。

<CgxTip>
模板集成对于 PDB 数据库中具有已知同源物的蛋白质特别有价值，其中结构保守性可用于显著提高预测准确性，相比纯序列方法。
</CgxTip>
